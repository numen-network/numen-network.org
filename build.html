Get started

Run a node

Prebuilt archives cover Linux x86-64 and macOS arm64. Each one holds the numen binary and mainnet-raw.json. One command syncs the chain and serves RPC. Pass testnet-raw.json instead to join the testnet.

Quickstart

Run the latest numen node

  • Open TCP 30333 on your firewall to help strengthen the network.
  • Open UDP 123 both ways as well, or NTP never gets through. Drift past 2 seconds and the node rejects new blocks, stuck on its own fork.
$ ./numen --chain mainnet-raw.json
Keep the full history
$ ./numen --chain mainnet-raw.json --state-pruning archive

systemd

Run it as a service

A systemd unit keeps the node up across reboots and crashes. Put the binary and chain spec under /opt/numen and save the unit as /etc/systemd/system/numen.service.

[Unit]
Description=Numen node
After=network-online.target
Wants=network-online.target

[Service]
Type=exec
ExecStart=/opt/numen/numen \
    --chain /opt/numen/mainnet-raw.json \
    --in-peers 100 \
    --out-peers 25 \
    --in-peers-light 50
Restart=always
RestartSec=5s
LimitNOFILE=65536

[Install]
WantedBy=multi-user.target
Enable and start
$ systemctl daemon-reload && systemctl enable --now numen
Follow the log
$ journalctl -u numen -f
Take part

Mine asteroids

Scanning asteroids is the work. You mine with a payout address only. The node never holds a private key.

Quickstart

Mine with the node scanner

$ ./numen --chain mainnet-raw.json --miner <YOUR_ADDRESS> --node-miner <THREADS>
--minerReward address in SS58. Also opens the mining RPC. --node-minerScans on every core. Add a thread count to cap it. Drop the flag to leave block authoring to external miners.
  • Generate the keypair offline, for example with subkey generate, and pass only the SS58 address. Keep the private key on a separate machine.
  • An invalid SS58 address stops the node at startup.

External miners

Drive the mining RPC

With --miner set and --node-miner dropped, the node hands out tasks and accepts seals over JSON-RPC. Each task carries preHash, difficulty, miner and protocol. The scan itself is public code, so a miner of your own starts from the poscan crate and the Spectral3D library.

mining_getTaskpulls the current task
mining_subscribeTaskpushes a fresh task every second
mining_submitSealaccepts a found seal

Polkadot-API
