PoScan · Proof of Scan

The scan is the work

The work is geometry, not a table of hashes. Every attempt grows a deterministic asteroid from its seed, scans its surface, and hashes the spectrum. Verifiers replay the same pipeline once per seal.

STEP 1 · DERIVE
seed = H(pre_hash ‖ addr ‖ nonce)

Work is bound to this block and this miner. No precompute, no cross-block replay.

STEP 2 · GROW
asteroid_det(seed, sd=4)

A deterministic asteroid, 2,562 vertices, noise field recast per seed. Miners can't bring their own mesh.

STEP 3 · SCAN
spectral3d.scan(mesh, 4096)

4,096 surface samples → a 23-dimension spectral signature. This step is the workload itself.

STEP 4 · QUANTIZE + HASH
s = H(protocol ‖ round(feats / ε))

Fine buckets (per-dim ε ≈ 1e-6) hash into full-entropy work. Low-res and surrogate shortcuts measurably die.

STEP 5 · SEAL
s < target → block

Otherwise nonce+1 and grow the next asteroid. The winning asteroid is rebuilt on-chain with the block.

Hybrid consensus

PoW proposes BFT disposes

Two independent roles: anonymous miners race to produce blocks, a bounded validator set votes them irreversible. Reorgs before finality are normal physics, not incidents.

PRODUCTION

PoW mining · open to anyone

Target block time10 s
Participationpermissionless · anonymous
Block reward16 units
Halving12.5M blocks (~4 years)
FINALITY

GRANDPA voting · bounded set

Finality≤ 30 s · irreversible
Threshold2/3+ of validators
Set sizeup to 1,000 · coin locked
Session rotation60 blocks (~10 min)
ASERT DIFFICULTY · SELF-HEALING
next_target = anchor_target × 2^((Δt − 10s·Δh) / 1800s)

Absolute and anchor-based. No recursive drift, no oscillation. Every 30 minutes behind schedule halves the difficulty, and after a long stall the anchor resets, so hashpower can vanish and the chain still recovers on real time without flooding itself with junk low-difficulty blocks.

Spectral3D · the library behind PoScan

Shape is identity

The library behind PoScan exists for more than mining: it turns a physical object's geometry into a stable digital fingerprint. One object, one HASH ID.

NFTs sign the file

Flip one bit → a new hash → endless "originals". The asset and the object never truly bind.

We hash the shape

The same object at any pose, on any scanner, with a little noise → the same HASH ID. Offline, no trusted backend.

Spin up a Numen node from a release build. Prebuilt binaries cover Linux x86-64 and macOS arm64. Prefer your own toolchain? Build it from source.

Quickstart

Run the latest release

The archive holds the numen binary and the chain spec. Nothing else to download. One command syncs the chain and serves RPC.

$ ./numen --chain testnet-raw.json

Mine asteroids

Scanning asteroids is the work. You mine with a payout address only. The node never holds a private key.

Quickstart

Mine with the node scanner

--miner sets the payout address and opens the mining RPC. --node-miner scans on every core. Cap it with a thread count, or drop it and drive external miners over mining_getTask, mining_subscribeTask, and mining_submitSeal.

$ ./numen --chain testnet-raw.json --miner <YOUR_ADDRESS> --node-miner
